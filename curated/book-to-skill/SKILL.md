# Book-to-Skill Converter

Transform written knowledge into actionable agent skills by extracting structure — not producing summaries.

**Full original repository**: https://github.com/virgiliojr94/book-to-skill

This is a curated pointer + core description for easy access in Claude Code, Cursor, and Grok environments. For the complete converter (including the extract.py tool and full documentation), clone the original repo.

## Quick Use with Claude / Grok
Provide a PDF or book path and ask the agent to convert it into a skill focused on radiology, ABR Core topics, or clinical frameworks.

## Why this is valuable for radiology residents
- Turn Core Radiology, Requisites, or ABR review books into queryable skills
- Extract high-yield frameworks and differentials into living knowledge bases for ABR-Core-Mastery
- Build custom teaching skills for ResidentShield
